# activity_enroll

## 适用场景
当用户希望基于本地 Excel 文件，为指定营销活动报名优惠、券、权益或促销规则时使用。

## 必要信息
- excel_file_path：本地 Excel 文件路径，目前只支持本地文件。
- activity_id：要报名的活动 ID。

## 主 agent 需要提炼的信息
- 用户明确给出的 Excel 文件路径。
- 用户明确指定或从上下文能确定的 activity_id。
- 用户对报名范围、过滤条件、忽略列、特殊要求的补充说明。
- 用户是否在确认、取消或修改一个既有报名确认卡片。

## 子 agent
entry_agent: activity_enroll_agent

## 子 agent 输入协议
```json
{
  "excel_file_path": "本地 Excel 文件路径",
  "activity_id": "活动 ID",
  "compressed_context": "主 agent 提炼后的上下文"
}
```

## 标准流程
1. 读取并摘要 Excel 内容。
2. 由 LLM 基于真实列名、样例行和行数解释哪些字段与报名相关，哪些字段会被忽略。
3. 生成报名预览。
4. 在执行报名之前返回 HITL 确认卡片。
5. 用户确认后才允许执行报名。

## HITL 规则
- 未展示确认卡片或用户未明确确认时，不得执行报名。
- 确认卡片必须说明 activity_id、文件路径、识别到的优惠数量、关键字段、风险或缺失信息。
- 用户可以确认、取消或修改，主 agent 需要根据用户最新输入决定是否恢复、废弃或重建报名任务。

## 异常处理
- 文件不存在、读取失败、摘要失败时，子 agent 应用自然语言解释原因，并返回可恢复状态。
- 报名提交必须使用幂等键，提交结果未知时不得重复提交，需先查询操作状态。
